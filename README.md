# Absensi Guru SMKN 1 Negara Batin - APK

Project ini membungkus aplikasi web `index.html` menjadi aplikasi Android menggunakan Capacitor.

## Cara build
1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka tab **Actions**.
3. Pilih workflow **Build APK Absensi Guru**.
4. Klik **Run workflow**.
5. Setelah selesai, buka hasil workflow dan download artifact:
   `absensi-guru-smkn1-negara-batin-apk`
6. Di dalam artifact terdapat `app-debug.apk`.

Aplikasi membutuhkan koneksi internet karena versi HTML saat ini memuat beberapa library dari CDN.
